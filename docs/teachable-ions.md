# Teachable figures · ion charge
**Claim:** An atom's net charge changes when electrons are added or removed, even when the proton count stays fixed.
**Misconception:** Adding an electron makes an atom more positive.
**Learning loop:** Predict gain of one electron → adjust electron count in a 3D schematic → read charge → explain → apply to oxygen.
**Model:** Net elementary charge = proton count − electron count. Lightweight two-shell Bohr representation is an illustrative diagram of the first selected elements, not a quantum probability cloud, a time simulation, or a valid description of electron trajectories.
**Controls:** Element, electron difference (−1..+1), rotation. No automatic motion; WebGL is isolated to this route and uses on-demand rendering.
**Privacy:** No answers persisted. No model or source downloaded at runtime.
Method adapted from https://github.com/ywEdAi/teachable-figures (not vendored). Test with lint, typecheck, unit tests, build, keyboard, reduced motion, and 320/390px viewports.
